# Урок 9b: Быстрый контекст — стратегия grep-first

Агент, которому нужно «найти, где используется функция `formatDate`», по умолчанию делает наивно: читает файл за файлом, пока не наткнётся на нужное. Это медленно, дорого и засоряет контекст. Стратегия **grep-first** («сначала поиск») переворачивает порядок: сначала искать, потом читать. И весь приём — это **два предложения в промпте**, а не новый инструмент.

---

## Проблема

Наивный поток агента при исследовании:

```
Шаг 1:  read src/index.ts         → 400 строк в контекст
Шаг 2:  read src/utils.ts         → 350 строк в контекст
Шаг 3:  read src/components.ts    → 600 строк в контекст
... 20 файлов, 30 шагов ...
Шаг 30: наконец нашёл formatDate в src/dates.ts
```

Итог: **20 файлов** прочитаны (весь контекст забит), **30 шагов** потрачено (лимиты шагов сожжены), а нужен был один файл. Модель по умолчанию «читает», потому что чтение — самый универсальный инструмент, а поиск требует формулировки regex.

Причина не в инструментах — `grep` уже есть в наборе. Причина в **приоритете**: ничто не говорит модели «сначала ищи, потом читай».

---

## Решение с кодом

Два предложения в системном промпте меняют весь поток. Инструменты остаются те же:

```typescript
sections.push(`# Search Strategy
Search before reading. Use grep first.

Before opening a file, use grep to locate the exact symbols, functions, or
patterns you need. Read the file only after grep has narrowed down the location.
A 2-second grep can replace reading 20 files.`);
```

> **📝 Перевод промта (секция Search Strategy):**
>
> *«Сначала ищи, потом читай. Используй grep в первую очередь.*
>
> *Прежде чем открывать файл, используй grep, чтобы найти точные символы, функции или паттерны, которые тебе нужны. Читай файл только после того, как grep сузил местоположение.*
> *Двухсекундный grep может заменить чтение 20 файлов.»*

Вот и весь приём. Два предложения — **«Search before reading. Use grep first.»** — это вся стратегия.

### Результат: тот же вопрос, другой поток

```
Шаг 1:  grep "formatDate" glob "*.ts"     → 3 совпадения в src/dates.ts
Шаг 2:  read src/dates.ts                  → 1 файл, 40 строк
Шаг 3:  готово, отчёт
```

| Метрика | Наивный поток | Grep-first |
|---|---|---|
| Файлов прочитано | 20 | 1 |
| Шагов | 30 | 3–5 |
| Токенов в контексте | ~десятки тысяч | ~сотни |
| Стоимость | высокая | низкая |

### Почему это меняется в промпте, а не в инструментах

Инструменты уже правильные: `grep` существует и описан (см. паттерн описания инструмента). Проблема была **не** в наличии `grep`, а в том, что модель по умолчанию выбирает `read` как «самый безопасный» вариант. Менять нужно **поведение по умолчанию**, а поведение задаётся промптом.

Если бы мы решали проблему инструментами (например, «запретить read, пока не вызван grep») — это был бы хрупкий костыль: жёсткое правило, которое ломается на легитимных случаях («прочитай этот конкретный файл целиком»). Промпт-инструкция мягче и точнее: она **смещает приоритет**, а не запрещает.

---

## Ключевые выводы

- **Наивный поток — чтение 20 файлов → 30 шагов.** Модель по умолчанию «читает», потому что read — самый универсальный инструмент.
- **Grep-first — поиск 1 файла → 3–5 шагов.** Сначала `grep`, потом `read` только нужного.
- **Весь приём — два предложения в промпте:** «Search before reading. Use grep first.»
- **Меняется промпт, а не инструменты.** Инструменты уже правильные; проблема была в приоритете по умолчанию.
- **Инструкция смещает приоритет, а не запрещает.** Жёсткий запрет `read` — хрупкий костыль, который ломается на легитимных случаях.

---

## Попробуй сам

1. Дай агенту (без секции Search Strategy) задачу «найди, где используется функция `formatDate`». Замерь число шагов и прочитанных файлов.
2. Добавь два предложения в промпт и повтори. Сравни: шагов, файлов, токенов.
3. Попробуй жёсткую версию: «запрещено вызывать read до grep» — и найди случай, где она мешает (например, «прочитай полностью `src/config.ts`»).
4. Сформулируй ту же стратегию для других пар инструментов: «сначала grep, потом read» → есть ли аналог для «сначала list, потом read»?
5. Проверь, что секция не мешает прямым задачам чтения («прочитай файл X и объясни») — инструкция должна работать как приоритет, а не как запрет.
